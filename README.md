# مخبز الخير — التحكم عن بعد (Android)

Remote control for the Khair Bakery POS: payments (never printed), today's Z-report, shifts, archive, categories,
and instant Arabic notifications when an employee starts / ends a shift.

* Download the APK from the **Releases** page and install it.
* On the shop computer press **Ctrl + Alt + P**, save that shop's connection codes, then on the phone use
  **إضافة كمبيوتر** with the phone code (`m_...`) and the 6-digit PIN shown on the computer.
* No codes are stored in this repository. Each shop uses its own pair of codes.
